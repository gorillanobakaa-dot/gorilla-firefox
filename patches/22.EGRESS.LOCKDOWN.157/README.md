# 22.EGRESS.LOCKDOWN.157

Every network caller, identifier and helper executable cut from Firefox 157 at the source. Each cut returns before the code that would send, with a `GORILLA UNLEASHED - PHYSICAL LOCK` comment, so no preference can turn it back on. Verified on the built browser by its own HTTP log, a decrypting proxy, the socket table and the packaged archives. Apply in order, after the snapshot groups.

- `002-excision-creep-in-157-ipc-glue-putilityprocess-ipdl-utilityp.patch`: Excision creep: in 157 ipc/glue/PUtilityProcess.ipdl, UtilityProcessManager and dom/ipc/ContentParent include PHWInference/HWInference from toolkit/components/ml/ipc (~150 new sites in ~20 files); the 155 excision of the ml DIRS entry cannot be carried without rewriting the utility-process framework.
